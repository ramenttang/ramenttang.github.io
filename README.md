# 포트폴리오 자료 (Materials)

> 디자이너 **선다연**의 포트폴리오 웹사이트를 만들기 위한 **재료 정리**.
> 원본: `portfolio.pptx` (19 slides / 114 media files) — 자료는 그대로 보존되어 있음.

이 디렉터리는 웹사이트 빌드에 들어가기 전 단계의 **재료 정리용**입니다.

## 자료 통계

- **슬라이드 19장** 중 프로젝트 13장 (Slide 6–18), 자기소개/이력 5장 (Slide 1–5), 마무리 1장 (Slide 19)
- **미디어 114개** 중 콘텐츠성 이미지 70개 추출 (200px 미만 데코·아이콘은 제외)
- **원본 보존** — `portfolio.pptx`는 그대로 둠

## 자료 추출 규칙

- 한 슬라이드의 **콘텐츠 이미지**만 추출 (장변 ≥ 200px, 면적 ≥ 40,000 px²)
- 데코 라인, 자격증 배지, 작은 아이콘 등은 제외
- 파일명: `slide{NN}-{원본미디어파일}.png` (예: `slide06-image50.png`) — 슬라이드 추적 가능
