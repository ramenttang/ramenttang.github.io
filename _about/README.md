## Introduction

> "도구의 제약을 지우고, 크리에이티브의 영역을 무한히 확장합니다."

다양한 분야를 향한 호기심을 원동력 삼아 **낯선 툴을 스펀지처럼 흡수**합니다.
3D 공간부터 모바일 UI/UX 화면까지, **소프트웨어 공학의 논리 위에 감각적인 시각 언어**를 더해 경계 없는 융합을 만들어내는 하이브리드 콘텐츠 크리에이터 선다연입니다.

### 강점 1 — 실무 환경에 맞춰 진화하는 적응력

펄어비스 인턴십을 통해 새로운 엔진 환경에 빠르게 적응해 모션캡처 데이터를 최적화하는 실무 파이프라인을 체득했습니다.
낯선 시스템 안에서도 캐릭터와 프랍의 상호작용 등 다양한 변수와 충돌 상황을 꼼꼼하게 수정하며, **기획된 움직임이 실제 환경에서 완벽하게 구동되도록** 결과물의 완성도를 끌어올렸습니다.

### 강점 2 — 시각화와 콘텐츠 수익화

10개월간 1인 상점을 운영하며 고객의 모호한 니즈를 3D 아바타로 시각화했습니다.
시각 가이드라인을 도입해 소통의 오차를 줄이고 페이셜 세팅으로 디테일한 감정을 연출하며, **크리에이티브를 실제 수익(200만 원)으로 연결**했습니다.

### 강점 3 — 빠른 학습력과 화면 설계

Figma와 Illustrator를 단기간에 독학해 **출결 앱 프로젝트의 전체 UI/UX 기획**을 총괄했습니다.
복잡한 시스템의 논리를 직관적이고 일관된 화면으로 풀어내며, **낯선 도구도 완벽한 결과물로 만들어내는 학습력**을 증명했습니다.
